# Contributing

- **Spec ambiguities:** open an issue quoting the section, what's unclear, and what you'd implement today.
- **Proposed changes:** see GOVERNANCE.md. While Draft: PR + 7-day window for normative changes.
- **Vectors:** disagreements between validators on a vector are the most valuable bug reports — include both outputs.
- **Ground rules for any PR:** no new top-level fields, ever; base-§4 canonicalization respected (no floats); examples must verify against the stock base verifiers.
