# Governance

Maintained by Allowly (Druim Pacific LLC) as profile editor, following the base repository's governance model in miniature.

- **Editorial changes:** PR, one maintainer approval.
- **Normative changes while Draft (< 1.0):** PR with rationale, 7-day comment window.
- **After 1.0:** additions that would invalidate previously-conformant receipts require a major version and an RFC-style discussion first.
- **Hard invariant at every version:** this profile never adds top-level receipt fields and never conflicts with the base format; where it would, the base governs and the profile changes.

Intent mirrors the base repo's: neutral standard over single-vendor artifact. Multi-implementer maintainership as soon as there are multiple serious implementers.
